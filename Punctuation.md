# Punctuation Guide

Bold: **Something here**

Italic: *being italicized* 

Strikethrough: ~~Opps, this is wrong~~

Underline: Here is <ins>important</ins> thing

Quoting text: This text is not a quote
> This one is 

|Punctuation   |Syntax   | Example  |
|---|---|---|
|Bold          |`**Something here**`      |**Something here**   |
|Italic        |`*being italicized*`      | *being italicized*   | 
|Strikethrough |`~~Opps, this is wrong ~~`|~~Opps, this is wrong~~| 
|Underline     |`<ins>important</ins>`    |<ins>important</ins> thing|
|Quoting       |`> This is quote`         |> This is quote    |
